# DOLI

Instead of competing based on computing power or stake size, the network uses sequential computations as proof that real time has elapsed, with blocks created according to a deterministic schedule.

The network operates on a UTXO model, without an EVM or general-purpose smart contracts. Tokens, NFTs, AMMs, lending, and other functions are implemented as native transaction types at the protocol level.

Rewards are collected into a common pool and distributed among active producers once per epoch, in proportion to the number of bonds held. One bond on mainnet equals 10 DOLI
